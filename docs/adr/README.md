# Architecture Decision Records

One page per decision that was genuinely contested — what we chose, what we gave up, and what
would make us revisit it. Not a log of everything; only decisions where a reasonable person could
have chosen differently.

Format: context, decision, consequences. Numbered, never renumbered. A superseded ADR is marked
superseded rather than deleted, because the reasoning that was wrong is often more instructive
than the reasoning that was right.
